## Software & Funktionen

* **VPD-Regelung:** Automatische Steuerung basierend auf dem VPD-Wert für optimale Bedingungen.
* **Individuelle Limits:** Temperatur und Luftfeuchtigkeit können manuell begrenzt werden, um das System abzusichern.
* **Visualisierung:** Flexible Dashboards mit Trenddiagrammen für eine einfache Datenübersicht.
* **Clock-Sync:** Synchronisation zwischen Hardware-Daten und UI-Anzeige für konsistente Echtzeitwerte.
